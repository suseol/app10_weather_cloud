# checkpoints - 중간에 놓쳤을 때 따라잡기

수업 중에 코드를 따라가다 놓쳤다면, 지금 진행 중인 단계의 **바로 앞 체크포인트**를 복사해서 이어 갈 수 있다. 폴더마다 그 단계를 마친 시점의 `lib/` 전체와 `pubspec.yaml`이 들어 있다.

| 폴더 | 여기까지 완성 | 실행하면 보이는 것 |
| --- | --- | --- |
| `S02` | Firebase 연결, 익명 로그인, 실습 서버 출입 등록 | "내 번호: xxxxxx \| 실습 서버 연결됨" |
| `S04` | 사진 파일 업로드(Storage), 사진 정보 저장(Firestore) | 사진 등록 뒤 "사진을 공유했어요." |
| `S05` | 실시간 사진 목록, 지역을 바꾸면 다시 구독, 클라우드 사진 배경 | 친구가 올린 사진이 바로 나타남 |
| `S07` | 좋아요, 보기 범위 칩 = **필수 실습 완성** | 하트 숫자, 1시간 ↔ 3개월에 따라 장 수 변화 |
| `S09` | 선택 실습까지 완성(인기순 정렬, 보던 사진 유지, 내 사진 삭제) | 좋아요 많은 최근 사진이 앞에, 내 사진에만 🗑 |

## 복사하는 방법

1. 앱 실행을 멈춘다.
2. 파일 탐색기에서 `checkpoints/<폴더>/lib` 안의 폴더와 파일을 모두 복사해, 프로젝트의 `lib` 폴더에 붙여 넣는다. "대상 폴더의 파일 덮어쓰기"를 고른다.
3. LMS로 받은 `lib/config/firebase_config.dart`는 체크포인트에 없으므로 그대로 남는다. 없으면 다시 넣는다.
4. 다시 실행한다(hot reload가 아니라 Run).

- 내가 고친 코드는 덮어써져 사라진다. 남기고 싶으면 먼저 `lib` 폴더를 다른 곳에 복사해 둔다.
- 이 폴더는 `analysis_options.yaml`에서 검사를 빼 두었다. 그래서 여기 있는 파일에는 빨간 줄이 생기지 않는다.
